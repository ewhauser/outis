# Documentation site

Astro + Starlight, the same stack as the ewhauser/celld fork's site. It publishes
to https://ewhauser.github.io/outis/.

```sh
cd site
pnpm install --frozen-lockfile
pnpm dev       # http://localhost:4321/outis/
pnpm build     # sync source docs, build search, validate internal links
pnpm preview
```

Use Node from `.node-version` and the pinned pnpm version in `package.json`.

Only the overview, `src/content/docs/index.md`, is authored here. Every other page
is generated by `scripts/sync-docs.mjs` from an explicit list of repository
documents: the README's Quickstart, Results and Limitations sections, the guides in
`docs/`, `MODEL_CARD.md`, `benchmarks/results/COMPARISON.md` and `CONTRIBUTING.md`.
The generated `docs/` pages are ignored by git. Edit links lead to the source
document, and relative links are rewritten to site pages or to GitHub. GitHub
alerts (`> [!WARNING]`) become Starlight asides. Do not glob the repository; add
new public sources to the list, and to the `paths` filter in
`.github/workflows/site.yaml`.

`.github/workflows/site.yaml` builds pull requests that touch the site or its
sources, and deploys pushes to `main`. Enable Settings → Pages → Source → GitHub
Actions once in the repository. The `github-pages` environment must permit
deployments from `main`. PR artifacts do not deploy.

For another host/base path, override both values:

```sh
SITE_URL=https://docs.example.com SITE_BASE=/ pnpm build
```

Internal link and anchor validation is part of the build; external URLs are not
network-checked.
